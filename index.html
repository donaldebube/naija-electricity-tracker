Connect Supabase (free)

To save community reports across devices, connect a free Supabase database. This takes about 3 minutes.

  1. Go to supabase.com and create a free account
  2. Create a new project (choose any name e.g. "naija-light")
  3. Go to SQL Editor and run: CREATE TABLE reports (id uuid default gen_random_uuid() primary key, area_key text, status text, role text, nickname text, message text, upvotes int default 0, created_at timestamptz default now());
  4. Go to Settings → API and copy your Project URL and anon key below
